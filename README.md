# Docker Workshop

Lab byte_layers « Docker, couche par couche » : une todo-list Node.js conteneurisée, publiée, reliée à MySQL, décrite avec Compose puis optimisée. Niveau débutant, 3 h 30 environ. Il se suit dans VS Code avec l'extension [byte_layers](https://marketplace.visualstudio.com/items?itemName=byte-layers.byte-layers), le cours est dans `.layers/`.

**Prérequis :** les bases du shell, `git clone`, Docker avec Compose v2, un compte Docker Hub pour la couche 03.

Adapté du [Docker workshop](https://docs.docker.com/get-started/workshop/) de la documentation Docker. L'application d'exemple, [docker/getting-started-app](https://github.com/docker/getting-started-app), est clonée au commit `6b025fc5` pendant le lab.
